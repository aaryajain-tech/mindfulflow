I have built this project "Mindfulflow" using Google AI Studio.
This project is website which allows users (age group 16-25) to calm down, get organized and journal their thoughts.

## Key Features:
-> Make your to-do list with speech to text feature
-> Use priority criteria to organize your tasks
-> Play relaxing games to refresh your mind
-> You can dump all your thoughts in the dump section about what work you have to do and AI will orgnaize it.
-> You can hear calm rain, breeze, ocean sounds to stay calm and ambient sounds to focus on your deep work.


## This project’s tech stack is:

-> Frontend: React 19 with TypeScript
-> Styling: Tailwind CSS 4
-> Build/dev tooling: Vite; tsx runs the TypeScript server during development
-> Backend: Node.js with Express
-> AI features: Google Gemini API, including text generation and text-to-speech
-> UI libraries: Motion for animations and Lucide React for icons

## Run Locally
**Prerequisites:**  Node.js
1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
